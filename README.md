## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Moazzam-Matin/portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser, or use the VS Code **Live Server** extension for local development.

No build step is required for the static website.

## Deployment

The portfolio is hosted using GitHub Pages. Updates pushed to the configured publishing branch are reflected on the live website after deployment.
